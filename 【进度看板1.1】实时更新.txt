■ 冻结不变量红线（违反 = 事故，详见 01/04/09 号文档）
════════════════════════════════════════════════════════════════════
1. GitHub path 冻结：assets/{asset-uuid}/{langCode}/{filename}，不用 slug
2. images.status 四态 uploading/ready/failed/deleting；公开查询只看 ready
3. GitHub write lease：resource_key=al:{asset_language_id}，TTL 120s，
   Supabase 持久化；⚠️ 长期规则：Contents API 409/422 冲突重试只是异常
   恢复，绝不可替代 lease
4. SHA 校验：GitHub response sha == 本地 git blob sha 才进 ready（不信任裸 2xx）
5. 删除：ready→deleting→GitHub delete→success/404→DB delete；失败留 deleting
6. makeImageUrl 是唯一 URL 出口；GITHUB_TOKEN 仅 Worker Secret；无图片代理；
   VITE_GITHUB_IMAGE_CDN_BASE 仅留空口
7. Credits：H2 幂等三态 + C6 无负余额 + 一 debit 一 refund；
   定价语义冻结 Single=单价 / ZIP=N×单张价 / Package=固定
8. 扣分只在服务端原子完成，前端零扣分路径
9. /asset/:slug 永久兼容；V1.0 语义不推翻
10. Storage cleanup 🚫 从未授权——Supabase 原件不得删除
